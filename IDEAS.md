## Paperclip AI
- **What:** Open-source agent orchestration platform — runs a "company" of AI agents with org charts, roles, ticketing, delegation, and cost routing from one dashboard
- **Why relevant:** REX already has multiple agents (Rexxie, intake bot, scheduler, etc.) — Paperclip could unify them with proper hierarchy and tracing
- **Fully local:** Yes — self-hosted Node.js server + React UI, no account required
- **Links:** https://paperclip.ing · https://github.com/paperclipai/paperclip

## Graphify AI
- **What:** Open-source tool that turns any folder (code, docs, PDFs, images) into a queryable knowledge graph for AI assistants
- **Why relevant:** Could index the entire ~/Desktop/REX folder so every AI session understands the full system instantly — 71x fewer tokens per query
- **Fully local:** Yes — MIT license, runs locally via Python
- **Links:** https://graphify.net · https://github.com/safishamsi/graphify
